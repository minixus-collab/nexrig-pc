How to choose RAM for a gaming PC: capacity, DDR4 or DDR5?

Start with the memory generation and form factor your PC supports. Choose capacity for your games and applications, then compare transfer rates and memory profiles. More gigabytes or the fastest kit does not guarantee more FPS.

What does RAM do in a gaming PC?

System memory temporarily holds data the processor and applications need. It does not replace storage: its contents are not retained after the PC shuts down. When applications need more memory than is available, the operating system can move some data to storage, potentially causing slowdowns.

System RAM and graphics card VRAM serve different roles. Adding RAM does not automatically increase your GPU’s dedicated video memory. Read our VRAM guide to understand the distinction.

16 GB, 32 GB or 64 GB: which capacity should you consider?

Start with your games’ official requirements and your software’s recommendations. Account for applications running during a session: browsers, communication tools, recording software and other tasks.

  • 16 GB: can suit many games and everyday uses, but is not enough for every title or configuration.
  • 32 GB: worth considering for demanding games, extensive mods or several applications running together.
  • 64 GB and above: should be justified by software, projects or workloads that need it, rather than an FPS promise.

These examples do not replace workload-specific requirements. Check memory use during a representative session and look for capacity pressure. Extra capacity is most useful when the current amount is a constraint; it does not guarantee better performance on its own.

DDR4 or DDR5: choose for your platform

DDR4 and DDR5 are not interchangeable. Contacts and electrical requirements differ. Never force a module into an incompatible slot. Supported generations depend on the motherboard and processor; some processor families can use either generation depending on the motherboard, but not any arbitrary kit.

Check exact documentation for the generation, maximum capacity, slot count and supported configurations. Desktops generally use DIMMs and laptops SO-DIMMs, but some laptops have soldered memory or another format. A DDR5 label alone does not establish that a module can be installed.

The motherboard manufacturer’s tested memory list, often called the QVL, is a useful check. Look for the complete kit reference, module count and test conditions. Absence from the list does not prove incompatibility; inclusion does not guarantee every setting in every configuration.

MT/s, latency and XMP or EXPO profiles

Memory transfer rates are expressed in MT/s. Some listings use MHz for a value representing the DDR transfer rate: check the specification before comparing. CAS latency, or CL, cannot be compared alone between kits with different transfer rates.

Gaming results depend on the processor, motherboard, timings and workload. A faster kit does not deliver an identical FPS increase in every game. Look for tests on a comparable platform rather than converting a transfer-rate difference into an FPS gain.

Why does a kit not immediately run at its advertised speed?

It may start with standard settings instead of its performance profile. Intel XMP and AMD EXPO provide memory settings you can select on a compatible platform. Speeds beyond the configuration’s standard specifications are overclocking and are not guaranteed for every processor, BIOS or module count.

Read the documentation before enabling a profile, then check stability. If errors appear, return to supported settings and consult the manufacturer. Do not change voltages blindly to reach an advertised value.

A two-module kit or several separate modules?

On a dual-channel platform, an appropriate arrangement can enable both memory channels. Use the motherboard’s recommended slots, usually specified in its manual for two modules. Module count alone does not establish channel configuration on every platform.

For a new installation, a kit sold and tested together simplifies selection compared with separately purchased modules. Mixing references or adding a second identical kit does not guarantee operation at the advertised speed. Four modules may require lower speeds than two, depending on the controller and platform.

Before installation, shut down and unplug the PC and follow the manual’s precautions. Check orientation, proper seating and clearance beneath the CPU cooler. Afterwards, verify detected capacity and test stability. Memory errors can also involve settings, the controller or other components; they do not automatically identify a defective module.

Frequently asked questions

Does more RAM always increase FPS?

No. If current capacity is sufficient, adding more may not improve smoothness. Speed and timings can have varying effects depending on the platform and game.

Can DDR5 be installed in a DDR4 motherboard?

No. Choose the generation and form factor explicitly supported by the system.

Should you upgrade RAM before the SSD?

It depends on the constraint. RAM serves working memory; an SSD provides storage and data access. Our SSD guide explains storage selection.
