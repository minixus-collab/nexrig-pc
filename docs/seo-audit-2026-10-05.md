# NEXRIG technical SEO audit — 5 October 2026

## Scope and result

Local source audit of 636 rendered pages: 634 indexable pages and two noindexed carts. All 634 indexable pages appear once in the sitemap and can be reached through links from the French or English homepage. Eight separately exposed blog source copies retain noindex and are absent from the sitemap.

The audit found no broken local links or resources, missing linked fragments, duplicate HTML IDs, missing/duplicate page titles or descriptions, duplicate titles/descriptions, incorrect H1 counts, non-self-referencing canonicals, missing/nonreciprocal language pairs, sitemap conflicts or invalid JSON-LD. The index has three child sitemaps. Original URLs remain intact.

Structured data counts: 582 Product, 634 BreadcrumbList, 38 ItemList and eight BlogPosting objects. Product markup contains no fictional offers, stock, reviews or aggregate ratings. These counts establish valid local JSON and the inspected relationships, not eligibility for Google rich results. Product pages without genuine offers/reviews should not be given invented data to qualify for enhancements.

## Fix implemented

Six external blog cover images lacked width/height attributes. Added dimensions and a stable 16:9 cover frame with `object-fit: contain`. The frame reserves space before download and displays the whole artwork, with letterboxing where needed. This is a declared presentation frame, not a claim about the remote files’ intrinsic dimensions. Existing GTA artwork receives the same frame. Article URLs, copy, canonical/hreflang and source-only noindex directives are preserved.

## Validation

- `python3 scripts/audit_seo.py`: zero errors and zero duplicate-title/description warnings after regeneration.
- `python3 -m unittest discover -s tests -v`: 15 checks passed.
- `node tests/browser-smoke.cjs`: passed responsive page layouts, categories, filters, bilingual cart behavior, persistence and failure states; no page errors.
- `git diff --check`: clean.

Run the reusable audit script after future renderer or content changes. Machine-readable snapshot: `docs/seo-audit-results.json`. It reports 218 external image occurrences across generated pages; this counts placements, not unique image URLs.

## Remaining checks and priorities

Current runtime blocks these external hosts, so the audit does not establish successful image downloads, authenticity, dimensions, licenses or continued hotlink availability. Prefer authorized, optimized local files for reliability. Do not misidentify generic-chip images as exact partner models.
2. Rerun mobile PageSpeed on the homepage, GPU category, a product and a blog after deployment. Existing user-provided homepage Lighthouse results were FCP 0.9 s, LCP 1.1 s, TBT 0 ms, CLS 0 and Speed Index 3.7 s. These are lab results from a single run, not a site-wide real-user Core Web Vitals pass. The touch-target fix needs a fresh live Lighthouse assessment.
3. Check Search Console sitemap status and indexing reports. Local valid XML does not prove Google’s sitemap fetch or indexing success. Inspect Google-selected canonicals and non-brand queries; avoid repeated requests for every page.
4. Confirm exact laptop SKUs/specifications and time-sensitive GTA VI claims. Supplied examples remain labeled; do not treat them as independently verified specifications or benchmarks.
5. Observe actual search queries before further keyword changes. No keyword-stuffing or blanket noindex was applied. Keep useful categories, products, guides and the builder indexable.

## Hosting limitations

This project is served under `/nexrig-pc/` on a shared GitHub Pages hostname. A project-level robots.txt cannot control root-host crawling, and favicons are selected by hostname rather than a project subdirectory. A custom domain provides independent hostname control. No new domain, hosting migration, robots block or Search Console submission was performed during this audit.
