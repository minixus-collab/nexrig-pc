# Storefront development roadmap

NEXRIG remains a fictional Moroccan store and SEO portfolio. Preserve all existing URLs, canonical tags and bilingual pages; demo prices, generic illustrations and proposed PC builds must remain explicit.

1. Shopping entry points: unified searchable catalogue, homepage shop links and full proposed PC configurations with component bills and the existing cart. This stage is implemented locally.
2. Consistent navigation: use a shared accessible menu across categories/products, with clear routes to components, laptops, gaming PCs and accessories; preserve keyboard controls and mobile access.
3. Richer product presentation: verify exact manufacturer references, obtain licensed model photographs, document source/licensing, and add meaningful specifications. Laptop families need exact regional SKUs before becoming configuration-specific listings.
4. Store information: expand About and Contact honestly and explain how the demo cart works. Delivery, returns, warranties, support contacts and business credentials require genuine supplied details; do not invent them.
5. SEO and performance: keep bilingual titles, canonicals, internal links and sitemaps; optimize licensed images and measure mobile loading/Core Web Vitals. Use Search Console data to prioritize query-specific pages.
6. Real commerce, only if the project objective changes: define actual business, inventory, price, tax, shipping, payment and order requirements; choose appropriate server-side commerce services and test the complete operational flow. Static demonstration pages alone do not constitute a functioning store.

Current proposed PCs require exact BIOS, CPU support, QVL, cooling mounts, component clearance and PSU connector verification before any claim of a validated or assembled build.
